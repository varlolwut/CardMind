# CardMind documentation

Use this page as the documentation map. The README remains a short product and
installation entry point; details live here so they can be maintained independently.

## Start here

- [Getting started](getting-started.md): release installation, first boot, Wi-Fi,
  provider setup, and the first prompt.
- [User guide](user-guide.md): carousel, keyboard controls, chats, voice, search,
  files, tools, backup, and updates.
- [Configuration](configuration.md): chat, STT, TTS, search, network, model, and
  secret-handling rules.

## Connected tools

- [Web console](web-console.md): browser control surface, sessions, chat, files,
  terminal, SFTP, settings, and local-network security.
- [SSH and SFTP](ssh-sftp.md): profiles, host-key trust, terminal controls, remote
  file transfers, and current constraints.

## Reference

- [Limits and compatibility](limitations.md): hardware and firmware limits, supported
  formats, provider requirements, and known trade-offs.
- [Security model](security.md): credentials, TLS roots, Web-console sessions, SSH
  trust, update verification, and data stored on microSD.
- [Troubleshooting](troubleshooting.md): setup portal, Wi-Fi, API/SSE, voice, Web
  console, SSH, microSD, boot, and recovery problems.

## Documentation rules

- Every document is written for someone installing or using a released build.
- Secrets, real SSIDs, user paths, and provider-specific private URLs never appear in
  examples.
- A feature is documented as available only after it is built and verified on the
  Cardputer ADV.
- Hard limits are recorded in one place and linked instead of copied into every guide.
